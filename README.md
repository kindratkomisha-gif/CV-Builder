CV Builder

A lightweight, fast, and user-friendly web tool for creating professional resumes with real-time preview and PDF export functionality.

Features:

Real-Time Live Preview: Changes typed into the form on the left instantly update the resume document layout on the right.
PDF Export: Utilizes browser print capability configured specifically for standard A4 paper formatting.
Dynamic Contact Fields: Easily add extra contact information (links, messaging handles, or socials) on the fly.
Clean Layout: Formatted specifically for A4 proportions with appropriate spacing and print rules.
Zero Dependencies: Built with pure Vanilla HTML, CSS, and JavaScript.

Tech Stack:

HTML5 — Document structure and input form
CSS3 — Interface styling, Flexbox layout, and @media print rules
JavaScript (ES6+) — Data binding, DOM manipulation, and dynamic field handling

Project Structure:

.
├── main.html      # Main HTML structure and form
├── style.css      # Application styles and print layout
└── skript.js     # Interactivity, data binding, and rendering logic


Getting Started:

No build process or external server dependencies required.
Clone the repository:
git clone https://github.com/your-username/cv-builder.git


Navigate to the project folder:

cd cv-builder
Open main.html in your web browser.

How to Save as PDF:

Fill out the fields in the left pane.
Click the "Download PDF" button.
In the browser print menu, select "Save as PDF" as the destination.
Ensure background graphics are enabled and margins are set to default for best results.
